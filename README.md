## 安装

1. 下载并解压上面的 zip
2. 打开 `edge://extensions`（Chrome 用 `chrome://extensions`）
3. 打开右上角（Chrome 在左上角）的「开发人员模式」
4. 点「加载解压缩的扩展」，选中解压出来的 `TabTidy-1.10.4` 文件夹
5. 详细步骤见 [使用说明.txt](使用说明.txt)
