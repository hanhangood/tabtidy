# TabTidy 发布页

一个把标签页按网站和主题自动归到浏览器原生标签组的扩展。**每次发版，这里都会更新。**

## 下载最新版

**v2.3.2** —— [TabTidy-2.3.2.zip](releases/TabTidy-2.3.2.zip) · 95 KB

> 「×」按锤子图标按钮重做：24px 圆盘底托 + 15px 灰叉，悬停转红、按下加深；修图标颜色被套件规则压住导致永远浅灰

## 安装

1. 下载并解压上面的 zip
2. 打开 `edge://extensions`（Chrome 用 `chrome://extensions`）
3. 打开右上角（Chrome 在左上角）的「开发人员模式」
4. 点「加载解压缩的扩展」，选中解压出来的 `TabTidy-2.3.2` 文件夹
5. 详细步骤见 [使用说明.txt](使用说明.txt)
